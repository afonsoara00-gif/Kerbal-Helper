Welcome to Kerbal Helper.

IMPORTANT: This program is not digitally signed, so Microsoft Defender SmartScreen might block it. To run it, simply click the underlined text and select "Run anyway."

The goal of this program is to help calculate values ​​without needing to do the math by hand; it can also be used for RP and offers some tips.
(Currently, only Delta-V calculation is available in this version.)

Note: This program runs entirely in the terminal.
